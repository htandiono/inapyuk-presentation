# InapYuk presentation

Web slides for the Purwadhika demo. Arrow keys or the Next button move between slides.

Awan presents Feature 1 (homepage, accounts, property tools). Hendrik presents Feature 2 (booking, payment, reviews, reports). Slides marked for both of us are the opening and the close.

## Run it locally

Open `index.html` in a browser, or from this folder:

```bash
npx serve .
```

## Put it on presentation.inapyuk.space

This folder is a static site. On Vercel, create a project from this repo, then add the domain `presentation.inapyuk.space`. The parent domain `inapyuk.space` is already on the team, so the subdomain does not need a new purchase.

The product itself stays in the InapYuk repo. These slides do not change it.
